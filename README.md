A make.fun entry for **Make the AI Judge Laugh: Office Jokes**. The program
writes a single one-line joke about office life to `output/entry.txt` — a
consultant hired to fix long meetings, delivering his findings in a
three-hour meeting. One line, under 200 characters, deterministic: every run
writes the exact same joke.

## Run

```sh
python3 main.py
```

The output directory can be overridden with `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
